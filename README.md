# La Casa Dulce · Landing page

Landing page responsive para una postrería (Barranquilla, Colombia). HTML, CSS y JavaScript puros, sin dependencias ni paso de compilación.

## Estructura

```
├── index.html
├── css/styles.css
├── js/main.js
├── assets/logo.png
└── README.md
```

## Ver en local

Abre `index.html` en el navegador (doble clic).

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube todos los archivos.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. En un minuto tu sitio estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Qué personalizar

- **WhatsApp:** número en `index.html` y en `js/main.js` (busca `573027124509`).
- **Precios, horario y testimonios:** en `index.html`.
- **Redes sociales:** enlaces del pie de página (ahora apuntan a `#`).
- **Colores:** variables `:root` al inicio de `css/styles.css`.
- **Tipografías:** Baloo 2, Montserrat y Caveat desde Google Fonts.
